Setup

Install or update Bob

Runs IBM’s installer in the background using npm. Downloads software from IBM and npm into this app’s private runtime folder. If Node is missing, installs an official Node 24 runtime from nodejs.org after checking its download checksum. Requires permission to install software.

Archive downloaded mail

Save a local snapshot as email files with downloaded attachments. This is not a complete server mailbox export. Uses up to 5 GB; files over 50 MB are skipped. Excluded domains are omitted. Use only where your company permits local mail archives.

Everything saves automatically on this Mac, with local recovery copies. Export an extra copy of tasks, projects, review history, preferences, and drafts. Attached files, your API key, and Outlook mail are excluded. Backup import is not yet supported.

Where is my information saved?

Your Mac user folder contains .outlook_assistant_config.json (settings), .outlook_assistant_tasks.json (tasks), .outlook_assistant_task_review.json (review history), and .outlook_assistant_chat.json (chat). Reply drafts are saved in .outlook_assistant_drafts.json; the browser also keeps a recovery copy. Automatic recovery copies are in .outlook_assistant_backups. A laptop restart does not erase these files.
